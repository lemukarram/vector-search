# Contributing to Laravel Vector Search

First off, thank you for considering contributing to this package! It's people like you who make the open-source community such an amazing place to learn, inspire, and create.

## Code of Conduct

By participating in this project, you are expected to uphold our Code of Conduct. Please be respectful and professional in all interactions.

## How Can I Contribute?

### Reporting Bugs

- Use the GitHub issue tracker to report bugs.
- Describe the bug in detail and provide steps to reproduce it.
- Mention your PHP and Laravel versions.

### Suggesting Enhancement

- Search existing issues to see if the enhancement has already been suggested.
- Open a new issue to discuss the enhancement before starting work.

### Pull Requests

1.  **Fork the repository** and create your branch from `main`.
2.  **Install dependencies** using `composer install`.
3.  **Add tests** for any new features or bug fixes.
4.  **Ensure tests pass** by running `vendor/bin/phpunit`.
5.  **Follow PSR-12** coding standards.
6.  **Update documentation** if your change affects usage.
7.  **Submit the PR** with a clear description of the changes.

## Development Setup

```bash
git clone https://github.com/your-username/laravel-vector-search-RAG.git
cd laravel-vector-search-RAG
composer install
```

## Running Tests

```bash
vendor/bin/phpunit
```

## Security Vulnerabilities

If you discover a security vulnerability, please send an email to the maintainer instead of using the public issue tracker.
